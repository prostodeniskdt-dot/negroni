# Фото карточек

Папка для **превью в коллекции, подборках, избранном** и миниатюр на странице рецепта.

## Куда попадает на сайте

- `/collection`, `/curations`, `/favorites`
- Связанные рецепты на странице партнёра
- Миниатюры внизу страницы рецепта

## Имя файла

Id рецепта из `src/data/recipes.ts`:

```
americano.png
milano-torino.png
yaroslavl-negroni.png
```

## Требования

| Параметр | Значение |
|----------|----------|
| Формат | PNG с прозрачным фоном |
| Размер | **900×1200 px** |
| Пропорция | **3:4** или **7:10** |
| Фон | Прозрачный |

Стакан по центру, низ бокала у нижнего края кадра. Без формата 9:16.

## Подключение

```ts
cardImage: '/images/cards/americano.png',
```

Поле **`cardImage`** в `src/data/recipes.ts`.

> Это **не** папка для страницы рецепта — для неё используйте `../recipes/`.
