# Фото карточек (коллекция и списки)

Папка для **фото коктейля на карточках** в коллекции, избранном, подборках и связанных рецептах.

## Куда попадает на сайте

- Карточки на `/collection`, `/favorites`, `/curations`
- Миниатюры на странице рецепта
- Пропорция медиа-блока: **3:4** (портрет)

## Имя файла

Используйте **id рецепта** из `src/data/recipes.ts`:

```
americano.png
milano-torino.png
yaroslavl-negroni.png
```

## Технические требования

| Параметр | Значение |
|----------|----------|
| Формат | **PNG** с прозрачным фоном |
| Размер | **900×1200 px** (оптимально) или **1050×1400 px** |
| Пропорция | **3:4** или **7:10** — лучше всего для карточки |
| Фон | Прозрачный |
| Вес файла | до 1.5 МБ |

## Как подготовить

1. **Не используйте 9:16** (1080×1920) — стакан будет слишком мелким в карточке.
2. Обрежьте PNG **плотно по контуру** стакана — без больших пустых полей.
3. Стакан **по центру**, стоит на «полу» кадра (низ бокала у нижнего края).
4. Гарнир не должен упираться в верхний край файла.
5. Проверьте на тёмном фоне: не должно быть белой «подложки» вокруг бокала.

## Схема кадра

```
┌─────────────┐
│   гарнир    │  ← 10–15% высоты
│             │
│   стакан    │  ← основная часть
│   стакан    │
│  ▓▓▓▓▓▓▓▓▓  │  ← низ бокала у нижнего края
└─────────────┘
     3 : 4
```

## Подключение в проекте

В `src/data/recipes.ts`:

```ts
image: '/images/cards/americano.png',
```

> Сейчас поле `image` используется и для карточек, и для страницы рецепта. Если нужны **разные** кадры для карточки и страницы — положите файлы в `cards/` и `recipes/` и попросите разработчика разделить поля в данных.
