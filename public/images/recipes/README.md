# Фото рецептов

Папка для **фото коктейля на странице рецепта** (`/recipe/[id]`).

## Куда попадает на сайте

- Большое фото в боковой колонке открытой карточки рецепта
- Экспорт в PDF

## Имя файла

Id рецепта из `src/data/recipes.ts`:

```
americano.png
milano-torino.png
yaroslavl-negroni.png
```

## Требования

| Параметр | Значение |
|----------|----------|
| Формат | PNG с прозрачным фоном |
| Размер | **1200×1600 px** |
| Пропорция | **3:4** или **7:10** |
| Фон | Прозрачный (без белого/чёрного) |

## Подключение

```ts
image: '/images/recipes/americano.png',
```

Поле **`image`** в `src/data/recipes.ts`.

> Это **не** папка для карточек в коллекции — для них используйте `../cards/`.
