# Фото рецептов (страница коктейля)

Папка для **главного фото коктейля** на странице `/recipe/[id]`.

## Куда попадает на сайте

- Большое изображение в боковой колонке страницы рецепта
- Пропорция блока на сайте: **3:4** (портрет)

## Имя файла

Используйте **id рецепта** из `src/data/recipes.ts` (латиница, через дефис):

```
americano.png
milano-torino.png
yaroslavl-negroni.png
```

## Технические требования

| Параметр | Значение |
|----------|----------|
| Формат | **PNG** с прозрачным фоном |
| Размер | **1200×1600 px** (или 900×1200 px минимум) |
| Пропорция | **3:4** или **7:10** |
| Фон | Прозрачный (без белого/чёрного) |
| Вес файла | до 2 МБ |

## Как подготовить

1. Снимите или отретушируйте стакан на **прозрачном** фоне.
2. Обрежьте лишнее пространство вокруг бокала (в Photoshop: «Обрезать по прозрачности»).
3. Стакан по центру по горизонтали, **низ бокала** близко к нижнему краю кадра (отступ 3–5%).
4. Оставьте немного места сверху для гарнира (цедра, долька).
5. Сохраните как PNG-24 с альфа-каналом.

## Подключение в проекте

В `src/data/recipes.ts` укажите путь:

```ts
image: '/images/recipes/americano.png',
```

> Если для карточки коллекции и страницы рецепта используется **одно и то же** фото, достаточно положить файл сюда или в `../cards/` и указать один путь в `image`.
