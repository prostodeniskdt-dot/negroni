# Фото авторов

Папка для **портретов авторов коктейлей** (барменов, создателей рецепта).

## Куда попадает на сайте

- Круглый аватар **32×32 px** на карточке в коллекции
- Портрет **4:5** на странице рецепта (блок «Бар и автор»)

## Имя файла

Рекомендуется id рецепта или фамилия латиницей:

```
yaroslavl-negroni.jpg
alexandra-taran.jpg
```

## Технические требования

| Параметр | Значение |
|----------|----------|
| Формат | **JPEG** или **WebP** (фото человека, фон не обязателен) |
| Размер | **800×1000 px** минимум (пропорция **4:5**) |
| Пропорция | **4:5** (портрет) — совпадает с блоком на странице рецепта |
| Кадрирование | Лицо и плечи по центру; важное не обрезать по краям круга-аватара |
| Вес файла | до 500 КБ |

## Как подготовить

1. Вертикальный портрет, человек смотрит в камеру или в профиль.
2. Нейтральный или барный фон, без мелкого «шума» за спиной.
3. Лицо в **центральной трети** кадра — на карточке коллекции фото обрезается в **круг**.
4. Свет ровный, без пересветов на лице.
5. Сохраните с качеством 80–85% (JPEG) или WebP.

## Проверка перед загрузкой

- Уменьшите превью до круга 32 px — лицо должно быть узнаваемо.
- Убедитесь, что при обрезке 4:5 голова не обрезана сверху.

## Подключение в проекте

В `src/data/recipes.ts` у рецепта:

```ts
authorImage: '/images/authors/yaroslavl-negroni.jpg',
```
