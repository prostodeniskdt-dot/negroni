# Фото авторов

Папка для **портретов авторов коктейлей** (барменов).

## Куда попадает на сайте

- Круглый аватар на карточке в коллекции
- Портрет в блоке «Бар и автор» на странице рецепта

## Имя файла

Id рецепта или фамилия латиницей:

```
yaroslavl-negroni.jpeg
alexandra-taran.jpg
```

## Требования

| Параметр | Значение |
|----------|----------|
| Формат | JPEG или WebP |
| Размер | **800×1000 px** минимум |
| Пропорция | **4:5** (портрет) |
| Кадрирование | Лицо в центре — на карточке фото обрезается в круг |

## Подключение

```ts
authorImage: '/images/authors/yaroslavl-negroni.jpeg',
```

Поле **`authorImage`** в `src/data/recipes.ts`.
